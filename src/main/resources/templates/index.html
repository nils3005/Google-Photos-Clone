Willkommen im Informationszentrum

Das "Meine Fotogalerie"-Programm ermöglicht es Ihnen Bilder lokal in einer Datenbank zu sichern.

Zusätzlich werden Ihre Fotos in einer modernen Übersicht dargestellt.

Mit einem einfachen Mausklick, auf ein von Ihnen hochgeladenes Bild, können Sie diese als Popup-Ansicht darstellen.

Bedienung

Laden Sie ganz bequem ein oder mehrere Fotos Ihrer Wahl über den Upload-Button oben rechts auf der Hauptseite hoch.

Fotos können Sie in der Popup-Ansicht genauso einfach löschen, wie Sie diese hinzugefügt haben.

Aktuell arbeiten wir an einem Papierkorb-Feature. Sobald dieser zur Verfügung steht werden Sie mehr erfahren.
