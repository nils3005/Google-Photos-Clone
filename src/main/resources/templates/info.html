Willkommen im Informationszentrum

Das "Meine Fotogalerie"-Programm ermöglicht es Ihnen Bilder lokal in einer Datenbank zu sichern.

Zusätzlich werden Ihre Fotos in einer modernen Übersicht dargestellt.

Mit einem einfachen Mausklick, auf ein von Ihnen hochgeladenes Bild, können Sie diese als Popup-Ansicht darstellen.

In dieser Ansicht können Sie das Foto, über die Knöpfe unten links, löschen und herunterladen.

Bedienung

Laden Sie ganz bequem ein oder mehrere Fotos Ihrer Wahl über den Upload-Button auf der Hauptseite hoch.

Fotos löschen: Klicken Sie in der Menüleiste auf "Bearbeiten". Dort könne Sie per Mausklick alle Bilder auswählen, die Sie löschen oder herunterladen wollen. Nachdem Sie ihre Auswahl getroffen haben, drücken Sie bitte auf linken Knopf zum Löschen oder auf den rechten Knopf zum Herunterladen.

Warnung: Momentan sind nur Foto-Dateien erlaubt.
